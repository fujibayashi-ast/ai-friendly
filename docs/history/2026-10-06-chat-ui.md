# 2026-10-06 チャット UI

#11 で決めたこと。仕様は [docs/assistant.md](../assistant.md)。

## Issue を分けた

* #11 は「チャット UI と LLM プロバイダの切り替え」だったが、規模が大きいため、UI（#11）と LLM プロバイダ（#27）に分けた
* UI を先に作るため、LLM の代わりに通信しない仮のボット（決まった言い回しで動く）を用意した。モデルなしで、ツールの実行・確認・エラーまで画面と流れを一通り試せ、テストにも使える

## 置き場所: 右下のボタン → 浮いたパネル

* 「右下のボタンから開くパネル」と「右側のドロワー」はどちらもよくある形。npm での公開を考えると、使う側が選べるのが望ましい
* ただし両方を入れるとサンプルとしてわかりにくいので、実装は右下のパネル（`FloatingChat`）だけにした
* 差し替えられるよう、中身（`Chat`）は置き場所に依存しない部品にし、会話の状態は `useChat` に分けた。ドロワーにしたいときは `Chat` を別の入れ物に入れる
* 画面の下に入力バーを置く案もあったが、チャット感が薄く、普通のサイトのチャットボットとして見慣れた形を選んだ

## ツールの表示: Command 名の小さな行

* 「Command 名を出す」「人向けの文にする」「出さない」の 3 つを、デバッグ表示のように切り替えられるのが理想
* サンプルなので、題材ごとに文言を用意しなくて済む「Command 名の小さな行」だけを実装し、`renderToolCall` で差し替えられるようにした

## デザイン

* サイトの配色（白黒 + 蛍光マーカーの黄 1 色）とシステムフォントをそのまま使う
* 黄を使うのは、右下のボタン・送信ボタン・ツールの行の Command 名（マーカーを引いたような地）だけ
* あなたのメッセージだけを吹き出しにし、AI の返事は地の文にした。カードが並ぶ見た目を避け、話し手の違いを形で見せる
* 角の丸みはパネル（大）・吹き出し（中）・話しかけ方の例（丸）の 3 段階
* フォントや細部は、実際に触りながら見直す前提

## 実装中に見つけたこと

* 仮のボットは、言語を切り替えると作り直される。ループが最初のプロバイダを持ったままだと、言語を変えた後の返事が前の言語になった。ツールと同じく、プロバイダもステップごとに最新を読むようにした
* ツールの結果を ID だけで探すと、仮のボットを作り直したときに ID が重なり、前のターンの行に後の結果が出た。ローカル LLM もターンをまたいで同じ ID を使うことがあるため、AI のメッセージの直後に続く `tool` メッセージから探すようにした
* スマホでは開いている間ボタンを隠すので、閉じたときのフォーカスは描画し直した後に戻す

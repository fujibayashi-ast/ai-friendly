# 2026-10-05 共通 UI パッケージ

#6 で決めたこと。使い方は [docs/ui.md](../ui.md)。

## shadcn + Tailwind v4 にした理由

* 参考リポジトリ（loop-study）と同じ構成にした。部品を `packages/ui` に置き、`theme.css` を export して、アプリは読み込むだけにする
* shadcn は部品のコードを取り込む方式で、プロジェクトのコードとして直せる（アクセシビリティの調整など）

## アクセントを蛍光マーカーの黄にした理由

* 「チュートリアルっぽい色」として、蛍光マーカーの黄・説明書のブルー・赤ペンの 3 案から選んだ
* 赤ペンは削除・エラーの赤（destructive）と区別がつかない。ブルーはよくある青に寄りやすい
* 黄は白地の文字色に使えないため、地の色としてだけ使う

## shadcn の標準から変えたところ

* フォーカスリングを半透明（`ring-ring/50`）から不透明にした。半透明だと白地とのコントラストが約 1.8:1 で、フォーカスの表示に要る 3:1 に届かない
* トグルの選択中を `accent`（灰色）から `primary`（黄）にし、文字色の枠線を足した。黄と白地の差は 1.4:1 で、色だけでは選択中を見分けられない
* `@/` の import を相対パスにした。アプリ側では `@/` を解決できない

## CLI が無関係のパッケージを足した件

* `components.json` の `utils` を `@/lib/cn` にしたところ、shadcn の CLI が `from "cn"` と書き、npm の無関係の `cn` パッケージを依存に足した
* すぐに取り除き、shadcn の標準の `@/lib/utils` に揃えた。CLI で部品を足したあとは `package.json` の差分を確認する
